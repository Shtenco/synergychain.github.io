03 · BASE ARB EXECUTION

Внешняя сделка имеет реальную цену и slippage.

BaseArbExecutor — execution component, а не accounting source. Он покупает/продаёт external asset по реальному market route, оплачивает fee/slippage и доставляет asset в custody/settlement path.

Input budget

Количество canonical USDC, которое route имеет право потратить. Источник должен быть Treasury/flash/other authorized capital class.

Min output

Slippage/MEV-aware minimum WETH/USDC result. `amountOutMin=0` неприемлем для production.

Destination proof

Внешний result должен попадать в разрешённый custody/settlement endpoint, а не просто исчезать в промежуточном wallet.

05 · SECURITY BOUNDARY

Bridge — один из самых опасных периметров системы.

Поэтому security state является частью economic state: validator quorum, pause, replay protection, per-asset limits и delayed recovery влияют на solvency.

Replay protection

Один external event не может mint representation дважды.

Validator quorum

Критический proof требует формально заданного threshold/attestation scheme.

Pause / circuit breaker

При mismatch или exploit suspicion новые mint/unlock операции останавливаются.

Per-route caps

Лимит ущерба даже при compromised route/relayer.

06 · BRIDGE CONSERVATION

Внутренняя копия может двигаться быстро.
Внешний asset должен где-то физически существовать.

Любая схема, в которой internal token увеличивается без соответствующего custody/credit/explicit liability, должна быть классифицирована как monetary issuance — не как bridge representation.
