01 · EVIDENCE SCALE

У каждой идеи есть уровень доказанности.

V18 запрещает переходить от красивой гипотезы к production language одним прыжком. Негативный тест повышает знание системы даже если «не улучшает результат».

L0Idea

Concept / hypothesis.

L1Formal

Specification, equations, threat/economic model.

L2Simulation

Reproducible numeric/state experiment.

L3Prototype

Working code/UI/local system.

L4Fork / testnet / lab

Integration with real semantics/environment.

L5Audited / independent review

Security/economics/engineering review.

L6Production

Live metrics, incidents, reproducible outcomes.

−Negative evidence

Failed test preserved as constraint.

04 · REAL ECONOMY R&D

Самый сильный external value — physical output.

Агро, переработка, energy и metallurgy рассматриваются не как «темы сайта», а как потенциальные productive cells с capex, opex, yield, customers, unit economics и measurable output.

Agro Cell

Input → cultivation/processing → output → customer → external cashflow. Нужны unit economics и season/risk model.

Recycling / Circular

Waste/resource input → sorting/processing → recovered material/product → sale.

Electro / Energy

Generation/storage/efficiency assets with measured kWh, availability, capex and maintenance.

Metallurgy / Materials

Process/material R&D with physical measurement, energy balance and independent validation.

05 · DEEP TECH

Самые рискованные идеи получают самую строгую маркировку.

Deep Tech страницы не должны звучать как готовые продукты до independent evidence. Их ценность — карта гипотез, экспериментов, assumptions и falsification criteria.

research

Cascade ORC / Low-grade Heat

Каскадное извлечение электроэнергии из низкопотенциального тепла. Следующий уровень: thermodynamic model → component loss → NET power → pilot.

research

LENR / Cold Nuclear

Высокорисковая physics branch. Нужны calorimetry, controls, independent replication and clear null hypothesis.

research

Graphene / Photonics

Lithography and compute-device hypotheses: materials, fabrication constraints, switching/optical metrics and manufacturability.

research

Piezo Memory / Compute

Piezoelectric state as potential storage/compute mechanism. Требуется retention/endurance/write-read model.

research

BioNeuro Compute

Bio-neuromorphic / biological-compute ideas with ethics, reproducibility and interface constraints.

research

HyperVRAM / Memory Architecture

Experimental memory hierarchy and acceleration concepts. Benchmarks must separate capacity, bandwidth, latency and power.
