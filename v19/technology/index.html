02 · NEXUS

Один интеллект.
Не одна власть.

NEXUS может быть самым узнаваемым технологическим символом портала — именно поэтому его authority boundary должна быть особенно ясной.

OBSERVEСобрать картину

Finance, markets, products, governance, infrastructure, research.

MODELПостроить сценарии

Forecast, causal hypotheses, constraints, uncertainty.

EXPLAINПоказать причины

Не только output, но inputs, assumptions и risks.

PROPOSEСформировать действие

Structured proposal с expected effects и evidence.

AUTHORIZEПередать институту

Человек/DAO/council принимает ответственность за решение.

03 · POSTQUANTUM

Криптография будущего
не строится на старых лозунгах.

V19 сохраняет V14 post-quantum ambition, но требует актуального cryptographic contract: стандартизованные primitives, provider abstraction, migration path, compatibility и независимый audit.

01

Provider interface раньше «собственной криптографии».

Архитектура должна позволять заменять primitives без переписывания всей экономики.

02

Hybrid migration раньше флага «PQ-ready».

Нужны lifecycle ключей, backward compatibility и операционный переход.

03

Audit раньше production claim.

README и test vectors не равны независимому security review.
